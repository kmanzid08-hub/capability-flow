# Development roadmap

## Phase 1 — foundation (this milestone)

Organizations, users, memberships, People records, authentication, role-aware access, and tenant isolation.

## Phase 2 — capability evidence

Qualifications, certifications, skills, languages, employment, project experience, documents, and completion evidence.

## Phase 3 — opportunity readiness

Opportunities, structured requirements, deterministic matching, readiness scoring, explainable matches, and gap analysis. No AI is required for the first matching engine.

## Phase 4 — ecosystem integration

Lead-generation API integration, webhooks, scoped API keys, bulk imports, and third-party integrations.

## Phase 5 — intelligence and enterprise

AI-assisted requirement extraction, semantic matching, subscription billing, SSO, advanced audit/security controls, and enterprise governance.

Each phase should preserve tenant scoping, add migrations rather than mutate schema history, and include adversarial cross-tenant tests before release.
